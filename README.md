# Olivo Librería

Sitio web de una librería de papelería con estética botánica. Presenta un catálogo de productos, reseñas y una sección de contacto; el carrito está indicado como una página en construcción.

Este proyecto fue realizado como trabajo práctico para un curso de programación Front End, con el objetivo de practicar la estructura y el diseño de páginas web usando HTML y CSS.

## Cómo verlo

Abrí `index.html` en un navegador. Desde la página principal podés navegar a las secciones de productos y reseñas, y a las páginas de contacto y carrito.
